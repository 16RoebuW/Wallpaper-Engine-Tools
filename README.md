# Wallpaper engine tools

Provides some simple tools for managing wallpaper engine playlists until better support is added natively.

# Features
- Add custom tags to workshop wallpapers
- Generate playlists based on tags
	- For example, you could create a playlist for "ambient" but **not** "landscape"
- Select a group of wallpapers to apply tags to
- Filter wallpapers by custom or built-in tag combinations
